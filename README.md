# zt10001.github.io

Personal website for Tao Zheng, built with Jekyll and the
[`no-style-please`](https://github.com/riggraz/no-style-please) theme.
Theme files are vendored from commit
[`2f8dba2`](https://github.com/riggraz/no-style-please/commit/2f8dba2c23633b21e45dce0fe2e34ec2d79bb1ca).

## Run locally

```bash
bundle install
bundle exec jekyll serve
```

GitHub Actions builds and deploys the site to GitHub Pages on pushes to
`master`.
